# Interest Hub

A 3D virtual environment created by Red Robo Studios.

## Current Features

- WASD movement
- Touch controls
- Helldivers Hall
- Solo Silo Monument
- Portal system

## Planned Features

- Book Dragon Library
- Books Portal
- Project Museum
- Minecraft Area
- Technology Wing

## Controls

W - Forward
A - Left
S - Back
D - Right

Touch and drag to look around.
