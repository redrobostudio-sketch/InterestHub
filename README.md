# Interest Hub

A 3D virtual environment created by Red Robo Studios.

## Current Features

- WASD movement
- Touch controls
- Helldivers Hall
- Solo Silo Monument
- Portal system

## Portals

- Orange = Helldivers, Built
- Green = Books, Not Built
- Blue = Music, Not Built
- Purple = Projects, Not Built
- Yellow = Minecraft, Not Built
- Red = Tech, Not Built

## Planned Features

- Book Dragon Library
- Books Portal
- Project Museum
- Minecraft Area
- Technology Wing

## Controls

W - Forward
A - Left
S - Back
D - Right

Touch and drag to look around.
